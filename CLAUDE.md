# Маршрут для Claude

При генерации DOCX-отчёта:

1. прочитай `README.md`;
2. прочитай `docs/ai-report-generation.md`;
3. используй `examples/docx/full-report.cjs` как основной шаблон;
4. открывай только нужные тематические страницы из `docs/docx/README.md`.

Не загружай Excel-документацию, если отчёт не содержит XLSX. Перед выдачей
результата обязательно выполни DOCX lint, сохрани файл и проверь его рендер.
