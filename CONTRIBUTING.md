# Вклад в проект

## Локальная проверка

Требуются Node.js 18+ и npm.

```bash
npm ci
npm run verify
npm run check:package
```

`verify` собирает проект, запускает тесты и проверяет документацию с примерами.
`check:package` устанавливает реальный npm-архив во временную директорию и
проверяет CommonJS, ESM и TypeScript.

## Правила изменений

- Не изменяйте публичный API без отдельного обоснования и миграционного плана.
- Для исправлений DOCX добавляйте тест, подтверждающий структуру результата.
- Генерируемый `dist/` должен соответствовать `src/`.
- Перед pull request выполните обе команды проверки выше.
- Не добавляйте в репозиторий результаты из `examples/**/out/`.

## Коммиты

Используйте короткие сообщения в стиле Conventional Commits:

```text
fix(docx): correct table width
docs: describe plantuml builders
```

Процедура выпуска описана в [RELEASING.md](RELEASING.md).
