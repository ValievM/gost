# Политика безопасности

## Поддерживаемые версии

До первой публикации исправления безопасности выпускаются только для актуальной
ветки `main`.

## Сообщение об уязвимости

Не создавайте публичный issue с деталями уязвимости. Используйте
[приватный security advisory](https://github.com/Magomed-cmd/gost/security/advisories/new).

Укажите:

- затронутую версию или commit;
- минимальный пример воспроизведения;
- возможное влияние;
- предложенное исправление, если оно известно.

Подтверждение получения и сроки исправления зависят от доступности сопровождающего.
